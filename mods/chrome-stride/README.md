# Chrome Stride

This mod lives in its own repository: **[cp2077-chrome-stride](https://github.com/penicius-code/cp2077-chrome-stride)**.

Sprint speed comes from leg cyberware, with a build-up, a stamina cost and a double-tap burst. Single-player only.

| | |
|---|---|
| Requires | redscript, TweakXL; Mod Settings optional |
| Status | 1.2.0 and 1.4.0 confirmed in game on 2.31; 1.4.1 to 1.4.3 not run in game; installed on 2.5 with no written test record |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-chrome-stride#readme).
