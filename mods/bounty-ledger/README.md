# Bounty Ledger and NCPD Uplink

This mod lives in its own repository: **[cp2077-bounty-ledger](https://github.com/penicius-code/cp2077-bounty-ledger)**.

NCPD bounties priced by wanted stars, alive pays more, payout later in one batch; a window shows the claim file. Single-player only.

| | |
|---|---|
| Requires | CET, redscript, Codeware, Mod Settings |
| Status | 1.0.0 tested in game on 2.31 (prices, alive claim, death downgrade, scan rule and batching seen; the payout itself was not reached in that test); 1.1.x not run in game in a written test; the Uplink window has been seen running in game (screenshot below) |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-bounty-ledger#readme).
