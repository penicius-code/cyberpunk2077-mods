# Bounty Ledger and NCPD Uplink

This mod lives in its own repository: **[cp2077-bounty-ledger](https://github.com/penicius-code/cp2077-bounty-ledger)**.

NCPD bounties priced by wanted stars, alive pays more, payout later in one batch; a window shows the claim file. Single-player only.

| | |
|---|---|
| Requires | CET, redscript, Codeware, Mod Settings |
| Status | 1.0.0 tested in game on 2.31 (prices, alive claim, death downgrade, scan rule and batching seen; the payout itself was not reached in that test); Bounty Ledger 1.1.7 and NCPD Uplink 1.0.0 in use in my game and working; Bounty Ledger 1.1.8 to 1.2.0 and NCPD Uplink 1.0.1 not run in game yet; no written test record |
