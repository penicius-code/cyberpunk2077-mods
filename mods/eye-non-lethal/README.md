# Eye Non-Lethal

This mod lives in its own repository: **[cp2077-eye-non-lethal](https://github.com/penicius-code/cp2077-eye-non-lethal)**.

A key that switches your Kiroshi optics to a non-lethal mode: hits on human enemies knock out instead of kill. Single-player only.

| | |
|---|---|
| Requires | redscript, TweakXL, Codeware |
| Latest version | 1.6.0 |
| Status | up to 1.3.0 confirmed in game on 2.31; 1.4.0 to 1.6.0 compile on 2.5, not yet play-tested |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-eye-non-lethal#readme).
