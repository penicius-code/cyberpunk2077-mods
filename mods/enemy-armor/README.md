# Enemy Armor

This mod lives in its own repository: **[cp2077-enemy-armor](https://github.com/penicius-code/cp2077-enemy-armor)**.

Armour for enemies by what they visibly wear, their faction and their rank, plus chassis armour for drones and mechs. Single-player only.

| | |
|---|---|
| Requires | redscript, RED4ext, Mod Settings, Ped Damage Overhaul 2077 |
| Status | in use in my game and working; no written test record for 1.5.0 (the 1.0.0 core was checked against a hit log on 2.31) |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-enemy-armor#readme).
