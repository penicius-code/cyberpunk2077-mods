# Endurance

This mod lives in its own repository: **[cp2077-endurance](https://github.com/penicius-code/cp2077-endurance)**.

Adds an Oxygen reserve on top of stamina that runs down with sustained effort. Single-player only.

| | |
|---|---|
| Requires | redscript, TweakXL, Dark Future |
| Status | in use in my game and working; no written test record |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-endurance#readme).
