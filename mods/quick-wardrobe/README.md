# Quick Wardrobe

This mod lives in its own repository: **[cp2077-quick-wardrobe](https://github.com/penicius-code/cp2077-quick-wardrobe)**.

Put Equipment-EX wardrobe items on and off from a window, with filters, outfits and a pinned mode. Single-player only.

| | |
|---|---|
| Requires | CET, redscript, Codeware, Equipment-EX |
| Status | 1.2.2 in use in my game and working; earlier versions were tried in game; no version has a written test record |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-quick-wardrobe#readme).
