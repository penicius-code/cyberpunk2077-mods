# Gorilla Yeet

This mod lives in its own repository: **[cp2077-gorilla-yeet](https://github.com/penicius-code/cp2077-gorilla-yeet)**.

Gorilla Arms punches launch the target as a ragdoll along your aim, with lootable bodies and an optional non-lethal mode. Single-player only.

Published on Nexus Mods as "Ragdoll Physics for Gorilla Arms Cyberware": <https://www.nexusmods.com/cyberpunk2077/mods/29014>

| | |
|---|---|
| Requires | Cyber Engine Tweaks, redscript |
| Latest version | 0.5.10 |
| Status | 0.5.2 released and in use, 0.5.9 and 0.5.10 not yet play-tested |

There is no code in this folder. Install, uninstall, settings and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-gorilla-yeet#readme).
