# Salvage

This mod lives in its own repository: **[cp2077-salvage-crew](https://github.com/penicius-code/cp2077-salvage-crew)**.

Salvage androids and a salvage drone collect loot from downed enemies after a fight; send them away to sell or recycle their cargo. Single-player only.

| | |
|---|---|
| Requires | Cyber Engine Tweaks, redscript |
| Latest version | 1.1.1 (game version 2.5) |
| Status | runs in game (the mod's own log shows deploying, looting, standby and service); no written test pass yet |

There is no code in this folder. Install, uninstall, settings and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-salvage-crew#readme).
