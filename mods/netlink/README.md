# Kiroshi NetLink

This mod lives in its own repository: **[cp2077-netlink](https://github.com/penicius-code/cp2077-netlink)**.

A computer screen inside the Kiroshi optics that opens on a key and follows you on foot and in cars. Single-player only.

| | |
|---|---|
| Requires | CET, redscript, Codeware, DigitalVixen Core; source only, not installable from the repo |
| Status | 1.1.0 and 1.3.0 used in game on 2.31; 1.7.0 failed its in-game test on 2.5; 1.7.1 in use in my game and working; no written test record |
