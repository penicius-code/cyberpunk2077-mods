# Custom Vehicles + Vehicle Bench

These mods live in their own repository: **[cp2077-custom-vehicles](https://github.com/penicius-code/cp2077-custom-vehicles)**.

Vehicle performance tuned from measurements: a bench logger times acceleration and top speed in the game, fitting scripts turn the numbers into drivetrain values, and a small mod applies them to add-on cars and bikes. Single-player only.

| | |
|---|---|
| Requires | Cyber Engine Tweaks; Cyber Vehicle Overhaul 2.1 (for Custom Vehicles) |
| Latest version | Custom Vehicles 1.2.5, Vehicle Bench 1.2.1 |
| Status | 1.0.0 to 1.2.2 benched in game; 1.2.3 to 1.2.5 not yet play-tested |

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/cp2077-custom-vehicles#readme).
