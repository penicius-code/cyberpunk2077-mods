# Vehicle Bench

This probe lives in its own repository, together with the mod it was built for: **[cp2077-custom-vehicles](https://github.com/penicius-code/cp2077-custom-vehicles)**.

A logger that times 0-60, 0-100 and 0-200 km/h and the top speed of the vehicle you drive and writes each run and a speed trace to CSV. Its measurements were used to fit the Custom Vehicles tuning. Single-player only.

|---|---|
| Requires | Cyber Engine Tweaks |
| Latest version | 1.2.1 |
